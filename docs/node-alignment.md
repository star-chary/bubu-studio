# 节点展示框吸附对齐

2026-10-16 本地完成并验证。本次只增加前端拖动交互，沿用已有坐标保存协议，不增加后端接口、数据库表、服务或依赖。线上发布与验收结果记录在本文末尾。

## 使用规则

- 拖动图片、视频、音频或空节点时，以素材展示框的左边、水平中心、右边以及顶边、垂直中心、底边寻找对齐位置。也支持一方边缘对齐另一方中心。
- 标题、上方下载 / 放大工具框、下方提示词输入框均不参与计算。展示框的几何尺寸与 `MediaNode` 使用同一个尺寸函数及标题高度常量，不使用原素材像素尺寸或整个节点高度。
- 距离参考位置不超过 6 个屏幕 CSS 像素时吸附；已经吸附后，拉开超过 10 像素再释放。两个方向独立计算，可单轴或同时对齐。缩放时换算为画布距离，保持屏幕上的手感一致。
- 优先选修正距离最小的参考位置；并列时优先邻近节点，再优先同类边 / 中心。已吸附的参考位置在释放前保持，避免附近多个候选导致跳动。
- 拖动期间显示蓝色虚线，覆盖两个展示框对应的范围，并在两端各延伸 8 个屏幕像素。线条不接收鼠标事件，线宽不随画布缩放改变。
- 松手后隐藏参考线并保留最终坐标；删除拖动节点、退出登录、进入参考选择、页面失焦、触摸取消或离开页面时清理临时对齐状态。删除对齐目标后清理对应提示，后续移动重新寻找目标。
- 播放和进度控件保留原有操作；参考选择模式仍禁止独立拖动节点、允许平移画布。上传节点继续不显示提示词输入框，生成节点保留原有展示条件。

## 实际数据流

```text
用户拖动节点
  → Vue Flow 处理指针、画布缩放和平移，得到未经吸附的位置
  → useNodeAlignment 取得自身及其他媒体节点的展示框
  → nodeAlignment 分别比较横向、纵向锚点，得到修正量和参考线
  → updateNode 替换节点 position，页面及引用连线同步更新
  → NodeAlignmentGuides 按当前视口将参考线换算到屏幕
  → 原有 useCanvasSession 观察坐标变化，600ms 防抖保存画布快照
  → 松手清理参考线；重新打开画布恢复已保存坐标
```

吸附是前端的实时交互，不需要每次移动请求后端。数据库仍只通过已有快照保存节点位置；参考线和当前吸附对象只存在于当前页面。临时画布沿用原规则，刷新不保留。

当前安装的 Vue Flow 1.48.2 在 `nodeDrag` 之前写入指针对应的位置，并保留自己的原始拖动记录。接入时替换节点的 `position` 对象，不原地修改该对象，因此不会把吸附后的坐标反复当成鼠标的原始坐标；自动平移也继续由原有拖动机制处理。松手事件只清理提示，不再次修正坐标。

节点布局当前没有嵌套分组，使用平铺节点的画布坐标；未来增加父子节点 / 多节点成组拖动时，需要扩展坐标转换及组边界规则。比较过程只读取节点数据，不在每次移动时读取所有节点的 DOM 边界。

## 核心模块

| 文件 | 职责 |
| --- | --- |
| `frontend/src/canvas/media.ts` | 展示框尺寸、标题高度、展示框坐标 |
| `frontend/src/canvas/nodeAlignment.ts` | 锚点匹配、优先级、吸附 / 释放距离、参考线几何 |
| `frontend/src/canvas/useNodeAlignment.ts` | 接入拖动事件、更新坐标、管理和清理临时状态 |
| `frontend/src/components/NodeAlignmentGuides.vue` | 不阻挡操作的屏幕参考线层 |
| `frontend/src/views/CanvasPage.vue` | 将对齐接入现有节点拖动及参考选择状态 |
