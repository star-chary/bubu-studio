# 视频提示词参数 UI

2026-10-07 当前状态：模型菜单扩展为 Seedance 2.5／2.0／2.0 fast／2.0 mini，文生视频已接通，模型能力与积分报价同步变化。首版仍仅提供 480p／720p。完整规则、数据流和验证边界见 [视频模型与文生视频](./video-models.md)。以下记录保留 2026-10-04 的界面阶段状态。

2026-10-04：视频生成控件已调整为底部三个入口：模型、生成类型、视频参数。仅调整现有能力的界面，生成按钮的模板、样式、禁用计算及任务提交逻辑保持原有实现。

## 已实现

- 模型菜单只展示当前接入的 Seedance 2.5，选中状态明确，不展示截图中的其他供应商模型、价格或预计耗时。
- 生成类型菜单显示“文生视频”和“全能参考”。本项目当前只接通 reference 模式，文生视频灰显为“暂未开放”；未实现的图生视频、首尾帧等选项不加入菜单。
- 当前节点没有参考素材时，全能参考置灰，提示添加图片、视频或音频。已有参考但未保存、读取失败、服务端判定不合格等情况，沿用现有参考校验，显示对应原因。只统计该节点已引用的素材，不根据整个画布里是否有媒体来判断。
- 参数入口显示 `比例 · 画质 · 时长`。弹层提供带图形的七种比例、480P / 720P 单选卡、4～30 秒滑块及数字输入。数字失焦时修正越界 / 非整数输入，空输入恢复当前值；滑块与数字保持同步。
- 保留原有“生成声音”复选框，放入同一参数弹层，其含义、默认值与提交字段不变。
- 菜单互斥展开，默认出现在入口上方，靠边时调整到窗口内；缩放 / 移动画布、调整窗口、放大输入框时同步定位或关闭。支持方向键、原生单选组键盘行为、Esc 先关弹层、点击外部关闭和滚轮不穿透画布。
- 视频面板移除旧的一排原生下拉框，桌面面板更紧凑，窄屏保留控件换行所需空间；图片提示词与模型控件保留。

## 数据流与范围

```text
VideoGenerationControls 选择参数
→ NodePromptPanel 发出 update:videoOptions
→ CanvasPage → useMediaNodes.updateVideoOptions(当前节点 ID)
→ 节点 data.videoOptions → 原有画布自动保存与刷新恢复
```

模型仍是固定 `doubao-seedance-2-5-260628`；生成类型仍是固定 `mode: reference`。画质值保存为 `480p` / `720p`，Auto 保存为 `adaptive`，时长保存为整数秒。没有新增接口、数据表、迁移或后端能力。原有任务仍复制提交时的参数快照，编辑参数不影响已经提交的任务。

`frontend/src/components/VideoGenerationControls.vue` 只管理菜单与输入交互，不复制节点业务状态、不调用模型。`NodePromptPanel.vue` 继续维护提示词、参考提示和原有生成按钮。原有音频参考校验没有改变。

## 官方能力核对与产品边界

2026-10-04 核对[火山视频生成说明](https://docs.volcengine.com/docs/82379/1520757?lang=zh)：Seedance 2.5 的全模态参考支持仅输入音频；Seedance 2.0 的纯音频限制不能套用到 2.5。因此完全没有参考时禁用全能参考，合格的纯音频参考继续可用。

[创建视频任务参数](https://docs.volcengine.com/docs/ark/create-video-generation-task-api?lang=zh&redirect=1)中包含更多模型能力；本轮只重排本项目已经接通的比例、480P / 720P 和 4～30 秒控件，不新增 1080P、4K、自动时长、批量生成或其他生成类型。文生视频保留为不可操作的菜单项，没有假装已经接通。
