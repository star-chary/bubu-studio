# 提示词素材引用：编辑与保存

2026-10-03：生成适配已完成，含标签的图片和视频可提交；输入快照、第三方适配和验收见 [第二阶段记录](./reference-generation.md)。

以下为 2026-10-02 第一阶段历史记录。已实现图片／视频节点的 `@` 引用编辑、真实画布资源菜单、引用关系同步及数据库保存恢复。本阶段不提供引用标签到模型输入的转换，也没有接入视频生成。

## 使用

- 在提示词任意位置输入 `@`，菜单上方显示当前节点已引用的图片／视频，下方“素材引用”只有图片、视频两个分类。可继续在 `@` 后输入名称过滤，也可使用菜单搜索框。
- 桌面悬停或点击分类打开右侧列表；窄屏点击分类进入子列表并可返回。上下键选择，右键进入分类、左键返回，Enter 插入，Esc 先关闭菜单、再次按关闭提示词面板。中文组词期间不处理菜单快捷键。
- 已引用素材只插入标签；新的素材同时加入参考列表并生成连线。同一素材可以在提示词里多次提及，但参考 ID 与连线不重复。
- 当前图片节点只能选图片，视频项展示原因并禁用；视频节点可选图片与视频。已有音频上传和旧参考入口保留，新的 `@` 菜单不展示音频、文本或资产。
- 标签是不可拆分的编辑片段，支持光标中间插入、整块删除、撤销重做、多行输入和放大恢复。复制输出可读纯文本，粘贴只接收纯文本，不从 HTML 或 `@名称` 自动创建引用。
- 删除标签只删除提示词中的这次提及，保留参考列表。移除参考或删除来源后，已有标签显示失效；从菜单重新引用可以修复。其他标签编号随参考顺序变化，但绑定的来源 ID 不变。

## 资源与保存流程

```text
GET /api/canvases/:id
  → canvases.snapshot + assets 中各节点当前资源
  → useCanvasSession 恢复 Vue Flow 节点
  → useNodeReferences 整理当前画布的图片／视频候选
  → PromptEditor 插入 reference 片段，同时更新 referenceIds
  → 提示词面板、缩略图、连线同步
  → PUT /api/canvases/:id → 后端结构校验 → snapshot JSONB
  → 刷新恢复片段与来源身份
```

菜单不单独请求数据库，不展示整个账户、历史任务产物或删除节点残留资源。候选来自当前画布节点；空节点不列入，有本地预览但未保存、保存中、读取失败、正在生成或归属不符的素材不可新增引用。保存过的暂时失效素材保留可解释状态。

`MediaNodeData` / 后端 `NodeData` 增加可选 `promptParts`：

```json
[
  { "type": "text", "text": "参考 " },
  { "type": "reference", "nodeId": "来源节点UUID", "kind": "image", "name": "茶叶.png" },
  { "type": "text", "text": " 的色彩" }
]
```

`nodeId` 是身份；`name` 是插入时保留的名称，供缺失素材时展示。缩略图、分类编号、当前名称由节点和参考列表派生，不保存 HTML、预览 URL 或编号作为身份。草稿跟随来源节点的当前资源；固定实际资源 Key 的任务快照属于第二阶段。

原有 `prompt` 保留为兼容文本投影（文字片段原文，引用片段为 `@` 加保存的名称）。含标签时两者一起保存，后端验证投影一致。删除全部标签后省略 `promptParts`，恢复旧的纯文本格式。旧画布无需迁移。

仍使用现有 `canvases.snapshot` JSONB，没有新增表、迁移、Redis 或队列。后端限制最多 1000 个片段、总投影最多 10000 个 Unicode 码点；验证类型、UUID、自引用、名称及图片节点的输入类型。允许保存来源已删除的引用片段，以便显示失效并修复；有效 `referenceIds` 仍须满足原有同画布节点关系校验。

## 第一阶段生成边界（第二阶段已替换）

含引用片段的草稿显示“生成适配尚未接通”，图片生成按钮禁用；提交函数也检查结构化片段。数据库模式下 `CreateTask` 在新任务入队前拒绝此类草稿，返回 409 `PROMPT_REFERENCES_NOT_READY`。已经创建的任务依然按原幂等键返回，不受后来草稿变化影响。

纯文本及原有“参考”方式的图片生成保持原流程。视频节点仍没有生成按钮。此处的阻止提交是第一阶段的显式范围，不代表供应商不支持引用。

后续需要实现片段解析、参考编号与媒体顺序的一致转换、不可变资源 Key 快照及后端可信校验，再核对所选供应商规则。不能把编辑器标签、HTML、节点 ID 或页面的 blob 地址直接传给第三方。
