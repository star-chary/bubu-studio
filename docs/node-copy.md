# 画布节点复制

节点右键或手机长按菜单提供“复制”和“复制副本”，空白处菜单提供“粘贴”。剪贴板只保存在当前画布页面，刷新或切换画布后需重新复制；可以多次粘贴，每次创建独立的节点 ID。画布达到 300 个节点时不能继续粘贴。

- “复制”保留节点自身的提示词文字、模型、参数和已有媒体；清除参考节点、首帧和提示词中的素材标签关联，原标签显示文字保留。
- “复制副本”保留上述内容及对现有参考节点的连接、首帧和提示词素材标签，不复制参考节点或下游节点。粘贴前参考节点被删除时只保留仍存在的关系，提示用户重新选择；失效的提示词标签保留以便修复。
- 生成中节点的副本不继承任务状态，也不会发起生成；若当时已有结果则复制当前展示的结果。
- 本地文件使用独立的浏览器预览地址并复用上传流程。尚未保存的本地文件和供应商临时结果仍受原有刷新丢失、临时地址过期限制。

## 已保存素材的数据流

```text
点击复制 → 页面内保存节点内容和素材身份 → 空白处粘贴，分配新节点 ID
→ 画布快照保存 copySourceKey → POST /api/canvases/:canvasId/nodes/:nodeId/asset-copy
→ 验证登录、画布归属、源素材属于同一画布且类型一致
→ OSS 同桶 CopyObject 到新节点目录 → 写入新素材记录
→ 前端切换到副本素材并清除快照中的待复制标记
```

已有 `assets` 记录仍按素材 key 唯一，复制后的文件和记录有自己的节点归属。服务端在写入素材记录前锁定画布并再次检查目标节点仍存在、复制来源没有变化；其他画布的素材无法通过这个接口复制。重复请求在已有副本记录时返回原记录。记录尚未写入时使用由目标节点 ID 确定的 OSS key，便于同一操作重试；若对象已复制而数据库写入失败或节点在复制期间被删除，可能留下未关联的对象，OSS 与数据库没有跨服务事务。

复制失败时节点保留“重新保存”入口；待复制的源 key 已写入画布快照，刷新或重新登录后可重新尝试。生成入口会等待素材副本保存完成。不会新增生成任务或积分流水；OSS 复制会增加对象存储用量与请求。原参考节点后续变化会影响副本未来使用的参考素材，但不会修改已生成的结果。

该功能不新增数据库表或迁移；只在已有快照 JSON 和素材记录 metadata 中增加可选字段。OSS 同桶复制需要源对象读取与目标对象写入权限。生产环境的实际 OSS 复制仍需单独验收，不能从模拟对象存储测试推断权限、网络或实际费用。
