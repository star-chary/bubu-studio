# 素材预览等待与重试

2026-10-11：本地实现并验证，尚未发布线上。本次只调整预览超过 30 秒的提示和独立的“重新加载预览”，未调整视频预加载方式、缩略图、封面、缓存策略或 OSS 读取逻辑。

## 页面行为

- 开始读取时显示“正在读取…”。超过 30 秒仍未成功，只提示“素材已保存，预览加载较慢。”，保留媒体元素和原请求；之后加载成功可直接显示图片或视频。
- 对尚未转存的生成结果，慢加载提示使用“素材已生成”；不把临时结果标记为已保存。
- 浏览器真正报告加载错误时，显示“预览加载失败”，不再未经检查就提示“链接已失效”。
- 已保存的素材或仍有临时结果地址的生成素材，在慢加载和失败状态下显示“重新加载预览”。没有可恢复地址的损坏本地文件保留原错误提示。
- 点击重试后回到“正在读取…”，重新开始当前预览的 30 秒提示计时。成功后隐藏提示和按钮；再次失败仍可手动重试。
- 不自动循环重试；真实网络故障、权限问题或文件损坏仍可能使下一次读取失败。

## 数据流

```text
生成完成 / 恢复画布
  ↓ 沿用已有结果地址与素材记录
MediaNode 挂载图片 / 视频并开始读取
  ├─ 超过 30 秒：仅显示慢加载提示，原读取继续
  ├─ 加载成功：更新节点尺寸和 ready 状态
  └─ 加载错误：显示失败，保留素材记录和可重试地址
       ↓ 点击“重新加载预览”
useMediaNodes.retryPreview 复用已有地址，递增页面内 previewAttempt
       ↓ MediaNode 重新挂载，旧视频停止读取，旧元素迟到事件不再回填
浏览器 GET /api/assets/content?key=原素材标识&previewAttempt=次数
       ↓ 沿用后端登录、素材归属检查和 OSS 读取
显示原素材
```

重试仅重新读取已有素材，不调用生成、上传或重试转存接口，不创建任务、不触发生成积分结算。`previewAttempt` 仅让浏览器发起新读取，不改变素材 key；供应商临时签名地址原样重用，不追加参数，也不回退到节点旧的已保存素材。

慢加载计时器属于 `MediaNode` 当前预览实例，加载完成、失败、重试或节点卸载时清理。`previewAttempt` 仅保存在前端运行状态，不写入画布快照；原任务、素材记录和提示词保持原值。没有新增数据库表、接口或第三方服务。

## 验证

在 `frontend/` 执行：

```powershell
node node_modules/@playwright/test/cli.js test tests/preview-retry.spec.ts tests/media-nodes.spec.ts --grep '生成图片|生成视频|刷新恢复的已保存素材|临时生成图片重试|本次生成完成|混合文件中' --workers=3
npm.cmd run build
```

10/10 项针对性 Chrome 浏览器回归通过：

- 图片、视频慢加载超过 30 秒后，原请求仍可成功显示。
- 图片、视频实际读取失败后连续重试并成功恢复；视频恢复后可播放。
- 图片、视频慢加载时重新请求，旧元素迟到错误不影响新预览。
- 无生成任务的已保存素材从画布恢复后，可提示慢并重试；刷新不保留重试次数。
- 临时生成图片重试不改变签名地址，不误用旧素材，保留尚未保存的提示。
- 当前生成任务刚完成后，新结果同样支持超过 30 秒继续等待。
- 原有损坏本地媒体错误提示和正常媒体显示通过。

预览专项验证了没有额外 POST / PUT / PATCH 等写请求，模拟任务数与积分状态不变。类型检查、生产构建通过；慢加载与失败提示已截图核对。接口与媒体来自项目测试夹具，没有请求真实方舟、OSS 或生产数据库；未运行全量功能回归。
