# 节点删除

2026-10-10：已随 `20261010T100525Z` 发布到正式站点，功能提交 `facfdd2`。本地与正式 HTTPS 前端产物的删除专项浏览器回归均为 13/13 通过。

## 操作

- 在图片、视频或音频节点上右键，显示“删除”菜单；复用画布“上传／添加节点”菜单的背景、圆角、尺寸、边缘定位、方向键和关闭逻辑。
- 普通点击节点后按 `Delete` 删除选中节点，也可在节点菜单内直接按 `Delete`。
- 点击生成节点仍展开提示词面板，焦点留在画布；点击输入区后进入文字编辑。输入框、提示词、参数控件、素材搜索、参考选择模式和离开确认框不会触发节点删除。
- 点击空白处取消选中；空白处右键打开画布菜单时也清除旧选中。`Backspace`、组合键、输入法组词及长按重复事件不触发节点删除。

## 数据流与边界

```text
节点右键“删除” / 画布选中节点后按 Delete
  ↓ CanvasPage 校验操作状态、确定节点 ID、关闭对应面板
useMediaNodes.deleteNodes 移除 Vue Flow 节点
  ├─ 清理本地预览 URL、加载计时器、排队文件及上传请求
  └─ useNodeReferences 清理其他节点中失效的 referenceIds
       ↓ 连线和参考缩略图随关系重新计算
useCanvasSession 通过现有自动保存写入新的画布快照
  ↓ PUT /api/canvases/:canvasId，沿用版本检查
Go / PostgreSQL 更新 canvases.snapshot
```

删除来源素材后，其他节点提示词里的 `@` 标签保留原名称并显示失效，生成入口提示修复引用；不自动改写创作文本。删除目标节点只移除该目标及关联连线，来源素材保留。

删除会终止该节点在浏览器内尚未完成的上传，并阻止等待画布保存的上传／生成继续提交。已经提交到服务端的生成任务继续执行和结算，任务记录及结果保留；迟到响应和刷新恢复不会重建已经删除的节点。已经存入 OSS 的文件和数据库资源记录仍保留，此操作不提供云端文件清理、任务取消、退款或回收站。

删除结果沿用 600ms 防抖自动保存及现有串行保存机制。保存失败时显示错误，点击“保存”重试；等待“画布已保存”再离开。临时画布只修改当前页面状态。

本次无新接口、数据库表、迁移或第三方服务；后端权限、快照校验、任务历史和积分处理继续使用现有实现。
