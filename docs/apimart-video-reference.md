# APIMart 视频参考与动作控制

2026-10-29 本地实现，尚未发布线上。Seedance 2.0、2.0 Fast 和 2.5 的全能参考支持单独引用视频或混合引用图片和视频；新任务的 Seedance 2.5 只开放 480p。Kling 2.6 Motion Control 和 3.0 Motion Control 使用一张人物参考图和一段动作视频生成。其他 APIMart 型号的视频参考及参考音频尚未开放。

## 素材与请求

| 型号 | 当前项目的视频输入 | 生成与请求 |
| --- | --- | --- |
| Seedance 2.0 / 2.0 Fast | 最多 3 段，单段至少 2 秒、合计最多 15 秒，短边 480～720 像素 | 用户指定输出时长；视频通过 `video_urls` 提交 |
| Seedance 2.5 | 最多 10 段，单段至少 2 秒、合计最多 30 秒；不额外限制短边 480～1080 像素 | 输出仅 480p、时长 4～30 秒；视频通过 `video_urls` 提交，声明普通参考任务 |
| Kling 2.6 / 3.0 Motion Control | 恰好 1 张人物图和 1 段 3～30 秒视频 | 输出时长跟随视频；按人物图与视频分别传 `image_url`、`video_url` |

动作控制当前使用「跟随参考视频的人物朝向」，以支持 20 秒素材，并保留视频原声；画质可选 720p / 1080p。人物图支持 JPEG、PNG、WebP 且不超过 10 MB；视频不超过 100 MB。两项大小是项目依据 APIMart 文档与指南采用的保守限制，其中接口文档将视频 100 MB 写作建议值。

项目沿用现有单素材保守校验，包括 MP4 / MOV、H.264 / H.265、24～60 FPS、画幅和像素范围。Seedance 2.5 的参考视频音轨只接受 AAC / MP3。当前入口要求填写提示词；Seedance 的参考模式不包含视频编辑、续写或单独音频参考。模型可用的素材类型、数量、时长和格式由前端提示，并由后端重新校验。

Seedance 2.5 已移除项目自行添加的短边 480～1080 像素检查，参考视频仍须满足其他尺寸和总像素要求。APIMart 文档列出的参考视频分辨率为 480p、720p、1080p，但未明确将其定义为短边的连续范围；超出原短边范围的素材是否能通过供应商审核，尚未进行真实生成验证。

2026-10-30 本次调整通过后端存储包测试和 17 项浏览器测试，其中以模拟素材元数据覆盖 `1000×450`、`2560×1440` 的提交及总像素限制；本地后端已重启加载调整。

APIMart 的 [Seedance 2.5 文档](https://docs.apimart.ai/cn/api-reference/videos/seedance-2-5/generation)要求含真人人脸的素材先进入其素材库审核；项目目前只传自有素材的临时访问地址，**尚未接入 APIMart 素材库和审核流程**，不能保证含真人人脸的参考素材可用。上游还会结合提示词判断任务类型，不匹配时可能异步失败。

## 报价与任务

价格表版本 `apimart-2026-10-29-v2` 使用 2026-10-29 APIMart 黄金价快照，并沿用项目固定积分换算。参考视频时长取自服务端保存的媒体信息，总时长向上取整；Seedance 将其与指定输出时长相加后乘以视频输入档价格，Kling 动作控制按参考视频时长和所选画质计价。没有视频参考时，Seedance 2.5 按输出时长计算。示例均假设输入与输出恰好 20 秒：

| 模型及输出画质 | 平台固定报价 |
| --- | ---: |
| Seedance 2.5 480p | 400 积分 |
| Kling 2.6 Motion Control 720p | 198 积分 |
| Kling 3.0 Motion Control 720p | 356 积分 |

Seedance 2.5 的上游每秒价格是估算，实际按 Token 结算；上游会员等级和最终账单也可能不同。平台固定积分不随真实账单重新计算，平台承担差额风险。参考 [Seedance 2.5 价格](https://apimart.ai/zh/model/doubao-seedance-2-5)、[Kling 动作控制接口](https://docs.apimart.ai/cn/api-reference/videos/kling-v2-6/kling-v2-6-motion-control-generation)、[Kling 2.6 价格](https://apimart.ai/zh/model/kling-v2-6-motion-control)和 [Kling 3.0 价格](https://apimart.ai/id/model/kling-v3-motion-control)。

```text
选择已保存素材 → 前端检查并请求固定报价
→ 后端校验用户、素材归属、模型和服务端媒体信息 → 展示积分
→ 提交时重新核价 → 同一事务冻结积分、保存任务和素材绑定
→ 后台重新探测素材、核对时长、签发临时地址 → 按型号提交 APIMart
→ 查询任务 → 结果转存 OSS 并登记素材 → 结算冻结积分
```

引用绑定固定素材 key；现有对象 key 随机生成，资产登记对已有 key 不覆盖。素材信息不符或真实文件时长与记录不一致时拒绝向供应商提交。明确失败退回积分；提交结果不确定或转存失败沿用冻结待核查流程。复用 `assets`、`generation_tasks`、`credit_accounts` 和 `credit_ledger`，没有新表或迁移；历史任务保留原报价及版本。

## 验证边界

本地使用模拟供应商与存储和独立测试数据库验证 20 秒参考素材元数据、报价、冻结、结算及明确失败退回；额外通过真实 HTTP 路由与隔离数据库验证 Kling 报价和任务创建，未启动供应商任务。后端全包测试、`go vet`、构建及前端构建通过。浏览器完整回归首轮 166/170 通过；修正一处原有空素材提示和三处历史测试断言后，相关 33 项全部复测通过，没有重新运行完整 170 项。浏览器使用模拟接口，未用真实 20 秒文件验收模型。没有发起真实付费生成、真实 OSS 转存或供应商账单核对，不能据此确认每个型号的上游实际可用性、效果或真人素材审核结果。
