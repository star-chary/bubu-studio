# 节点素材工具与输入框定位

2026-10-11 本地完成并验证；2026-10-13 已随 `20261012T161952Z` 发布线上，功能提交 `0c6c79e`。本次是前端交互更新，不增加数据库表、接口、服务或依赖。

## 使用规则

- 普通点击任意媒体节点，在节点上方显示深灰色矩形工具框，仅包含“下载”和“放大”。生成结果、上传图片、视频和音频都可使用；空节点显示工具框但按钮置灰。
- 输入框的展示条件保留：图片 / 视频生成节点（包括空节点）显示提示词面板，上传资源和音频节点不显示。点击画布空白处收起工具框和输入框；播放控件保留原有独立操作行为。
- “下载”读取当前原始素材，保存原文件字节，根据真实媒体类型补全文件后缀。读取过程中按钮显示“下载中”并禁止重复点击，失败显示错误，可再次点击重试；切换节点、素材地址变化或退出页面会取消尚未完成的读取。
- “放大”打开覆盖整个网页视口的预览层。图片按比例完整显示，视频 / 音频使用原生播放控件；关闭按钮和 Esc 均可返回，画布位置、缩放和提示词保留。打开时暂停对应节点播放器，关闭时释放预览播放器。
- 提示词面板的顶部始终等于节点底部的屏幕坐标加 12px，普通与放大尺寸都遵守这条规则。画布缩放只改变锚点，面板本身不随缩放；水平方向仍按窗口限宽，底部允许被裁切，不翻转到节点上方，也不自动平移画布。
- 参考选择模式保留：工具框暂时隐藏，点击来源节点只添加参考，提示词编辑目标不切换。

## 实际数据流

```text
普通点击节点
  ├─ CanvasPage.activeMediaId → 上方 NodeMediaToolbar
  └─ 原有节点类型 / origin 判断 → activePromptId → 下方 NodePromptPanel

点击下载
  → mediaActions.mediaSource 取得当前节点的 url，必要时回退到已保存素材地址
  → 同源私有素材使用已有 Session 读取；本地 Blob / 外部地址单独读取
  → 检查 HTTP 状态和响应媒体类型
  → Blob 原始字节 → 浏览器文件下载 → 释放临时对象地址

点击放大
  → CanvasPage.previewNodeId → 暂停节点内播放器
  → MediaPreviewDialog.showModal → 读取同一素材地址
  → 关闭 / Esc → 清理预览播放器、恢复工具按钮焦点
```

工具框、预览层和下载状态只在当前页面维护，不写入画布快照。下载及放大本身不创建生成任务、不上传新素材、不扣积分。生成节点被选中时仍会按已有规则获取积分报价。

私有素材读取继续经过已有后端鉴权和素材归属检查。外部供应商地址不会收到应用的身份头或 Cookie；签名地址保持原样。尚未转存的外部临时素材，下载仍受供应商地址有效期和跨域读取许可约束。普通已保存素材通过同源 `/api/assets/content` 读取。

下载当前先读取完整文件再交给浏览器保存，因此大文件需要等待读取完成，并占用临时文件内存。本次未改动 OSS 超时、缓存或视频编码。全屏预览超过 30 秒只显示等待提示，不主动中断；网络 / 解码失败与慢加载分开处理。

## 核心模块

| 文件 | 职责 |
| --- | --- |
| `frontend/src/views/CanvasPage.vue` | 独立维护工具框、全屏预览与提示词的目标节点，转换屏幕锚点，分流普通点击与参考选择 |

| `frontend/src/components/MediaNode.vue` | 打开全屏预览时暂停节点播放器 |
| `frontend/src/components/NodePromptPanel.vue` | 固定下方定位，工具操作保留当前输入框 |
