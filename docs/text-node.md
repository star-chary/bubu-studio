# 画布文本节点

画布右键菜单“添加节点 → 文本”可以新建文本节点；手机端通过长按画布空白处打开菜单。文本可直接编辑，也支持拖动、对齐、复制和删除。已保存画布里的文字会随画布自动保存，临时画布不会持久化。

图片或视频节点的提示词面板提供“文本”按钮。点击后从画布选择文本节点，再返回当前节点；可以选择多个，并在面板中移除。文本按选择顺序放在该节点自身提示词之前，不同段之间以空行分隔。空白文本不参与拼接；完整提示词仍受现有生成接口 2000 字符限制。文字中的普通 `@` 保持原文，已有图片或视频素材标签继续走原有素材绑定逻辑。

```text
文本节点编辑 → 画布草稿中保存文字
           ↘ 图片 / 视频节点保存文本节点 ID
点击生成 → 按顺序读取当前文字并拼接节点自身提示词
         → 保存画布 → 将完整提示词作为任务输入提交
         → 现有任务队列 / 模型 / 积分流程
```

已经提交的任务持有当时的提示词快照，之后编辑或删除文本节点不会改写旧任务；下一次生成使用新的文字。删除文本节点会移除其他节点对它的连接，复制生成节点时“复制”不保留连接，“复制副本”保留现有连接。文本节点自身没有模型、素材上传或独立生成任务。

## 数据与兼容性

- 文本正文以 `kind: "text"` 和 `text` 保存在原有 `canvases.snapshot` JSONB 中，图片 / 视频节点使用 `textReferenceIds` 记录有序连接；无需新增数据库表或 OSS 素材。文本和原有媒体 `referenceIds` 分开，避免文字参与素材文件校验。
- 包含文本节点的画布使用 `formatVersion: 1`；即使之后删除全部文本节点，该格式标记也会保留。旧版前端不认识文本字段，后端在保存时会原子检查格式版本，拒绝旧版客户端把较新格式的画布覆盖成旧格式；用户需要刷新到支持文本节点的页面后再编辑。原有画布版本冲突保护继续生效。
- 普通网页提交时发送拼接后的提示词，任务记录保存实际提交内容。MCP 生成入口从当前已保存的同一画布读取文本并按相同顺序拼接，报价和任务使用对应画布版本；本功能未新增 MCP 创建或编辑文本节点的工具。
- 文本节点正文输入上限为 10000 个 UTF-16 代码单元；表情等字符可能占两个。画布仍受 300 个节点和快照大小限制。
