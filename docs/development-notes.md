## 本地运行

环境要求：Node.js 20.19+（20 系列）或 22.12+，npm。本次验证使用 Node.js 24.13.0、npm 11.6.2。

本机先在项目根运行 `./scripts/start-postgres-wsl.ps1`，再启动后端和前端。PostgreSQL 运行在 D 盘 Ubuntu 子系统内，连接已配置到被忽略的 `backend/.env.local`；脚本及 Docker 备选说明见 [数据库启动](./persistence.md)。后端启动时自动应用数据库迁移。`DATABASE_URL` 是登录和业务接口的必需配置，留空时页面显示登录服务不可用。

```powershell
cd frontend
npm ci
npm run dev
```

打开 <http://127.0.0.1:5173> 进入首页，点击“新建画布”或已有画布卡片继续操作。服务只监听本机，端口被占用时会报错，不会悄悄切换端口。

后端使用 Go 1.26+，在另一个终端独立运行：

```powershell
cd backend
go mod download
go run ./cmd/server
```

后端从 `.env.local` 读取 `ARK_API_KEY`，配置模板是 `backend/.env.example`，已有本地配置不要覆盖。健康检查：<http://127.0.0.1:8080/health>，返回 `{"status":"ok"}`。端口通过 `PORT` 调整，默认 8080；前端开发代理需与后端端口一致。完整配置、接口约定与构建命令见 [后端说明](../backend/README.md)。

体验文生图：右键 → 添加节点 → 图片 → 点击节点 → 输入提示词 → 在面板左下角选择模型 → 生成图片。默认 Doubao-Seedream-5.0-lite，可切换 Doubao-Seedream-5.0-pro；当前仅这两个图片模型选项，均为单张、2K、保留水印。成功后图片回填发起生成的节点。体验图生图：先上传图片并等待“保存中…”消失，再在新图片节点点击“参考”、选择素材、输入编辑要求并生成；也可参考已转存的生成图片。视频节点可选择文生视频或全能参考；本地上传节点没有生成入口，避免覆盖导入的原素材。

启用 OSS：填写 `backend/.env.local` 中的 `OSS_REGION`、`OSS_BUCKET`、`OSS_ACCESS_KEY_ID`、`OSS_ACCESS_KEY_SECRET`，再设置 `OSS_ENABLED=true` 并重启后端。Endpoint 可留空，由地域推导；现阶段不需要自定义域名。资源按 `frame-space/dev/canvases/<画布ID>/<uploads或generated>/<images或videos>/<节点ID>/<资源UUID>.<扩展名>` 分层。详细配置、RAM 权限、接口与真实验收步骤见 [对象存储说明](./object-storage.md)。

## 画布交互

- 首页可命名新建或打开已有画布，卡片显示保存的布局与节点数。画布左上角“首页”先保存再返回；失败留在当前页，未上传素材离开前提示。每张画布使用自己的 ID、节点、草稿、引用、视口和任务记录。

- 左键或中键按住空白处拖动：平移。
- 鼠标滚轮：围绕鼠标所在位置缩放，范围 25%～200%。
- 工具栏 `−` / `+`：围绕视口中心缩放，百分比实时同步，到达边界时对应按钮禁用。
- “重置视图”：恢复偏移 `(0, 0)` 和 100% 缩放；空画布不使用依赖节点边界的“适应内容”。
- 启用数据库后，节点、输入草稿、所选模型、引用关系、位置与视口自动保存，也可点击右上角“保存”。刷新按地址中的画布 ID 恢复，并继续查询生成任务；右上角“任务记录”查看输入、状态、结果和失败原因。等待“画布已保存”再离开；未上传成功的本地文件只能恢复占位。
- 工具栏可通过 Tab 聚焦，再用 Enter / 空格操作。双击缩放关闭。
- 在画布空白处右键：在鼠标位置显示“上传、添加节点”；点击“添加节点”，同一个面板替换为“图片、视频”，没有其他条目。
- 菜单靠近窗口边缘时自动向内调整；点击外部或按 Esc 关闭。再次右键从第一层重新打开。可用上下方向键选择条目、Enter 操作。
- “上传”：可一次选择多个图片 / 视频 / WAV或MP3音频，在右键位置创建预览节点；同一批素材按两列排列，可重复导入同一文件。音频只作为上传素材，提供播放与进度控制。
- “添加节点 → 图片 / 视频”：在右键位置创建对应的空节点，只显示标题和占位图标。
- 节点可独立拖动；视频标题和画面都可拖动，单击 / 双击画面不会播放。只有独立的播放 / 暂停按钮控制播放，进度条可调整位置；控件操作不会拖动节点，视频不自动播放。
- 素材节点展示文件名和实际像素尺寸，图片 / 视频按原比例完整显示。非媒体和空文件会被跳过并提示；损坏、浏览器不支持或 30 秒内未读出首帧的文件显示错误状态。
- 点击任意图片 / 视频节点的标题或画面：弹出对应的提示词输入框，新建空节点和上传素材都支持。拖动节点、点击视频播放按钮或进度条不弹出输入框。
- 输入框默认显示在节点附近，空间不足时调整到窗口内；右上角按钮可放大为居中的编辑面板，再点可恢复。面板尺寸不受画布缩放影响，放大 / 恢复保留文字和选区。
- 输入面板参考用户截图采用宽幅深灰卡片、圆角、柔和灰色边框和紧凑节点标签；普通尺寸为 660 × 194，有参考时增高至 254，放大为 840 × 440，窄屏自动收缩。可生成的图片节点在底部显示模型选择、2K / 单张说明和生成按钮。
- 点击模型名称展开深色列表，选中项高亮并显示勾选；默认向上展开，窗口边缘自动调整。支持方向键、Home / End、Enter / 空格选择；Esc 先关闭列表，再关闭编辑器；点击列表外关闭列表，滚轮不穿透画布。
- 不同节点分别保留草稿和所选模型，新节点默认 Lite；普通编辑时点击外部或按 Esc 关闭，重新打开仍能看到该节点的文字和选项。生成任务保留提交时的提示词与模型快照，等待期间的修改只影响下一次生成，返回结果仍写入原节点；启用数据库后这些数据可刷新恢复。
- 提示词需为 1～2000 字。生成中显示状态并禁用重复提交；失败显示中文提示、保留草稿及已有图片，可以手动重试，没有自动重试。模型返回地址后加载图片，读取真实尺寸；同一地址重复返回时复用已加载预览，不会卡在加载中。
- 点击输入面板“参考”：顶部显示蓝色选择提示，锁定当前目标节点；随后点击符合规则的素材，可连续添加多个参考，重复点击不会重复添加。放大的输入面板会先收起，让画布可见。
- 图片节点只能参考图片；视频节点可参考图片、视频和音频。素材必须成功加载；自身、空节点、读取失败或类型不符的素材不能选。视频参考列表显示分类编号，以及未保存、格式 / 尺寸 / 时长不合格等原因；可编辑引用草稿不代表已满足模型调用条件。
- 已选参考在输入面板显示编号缩略图；画布显示“素材 → 目标节点”的曲线和箭头，拖动节点、缩放或平移画布时同步更新。缩略图右上角 `×` 移除引用及对应连线，不删除源素材。
- 选择期间可平移 / 缩放画布，暂不拖动节点或打开右键菜单；点击视频的独立播放按钮仍只控制播放。点击素材画面加入引用，不会切换当前提示词编辑目标。
- “返回节点”结束选择并定位目标；蓝条 `×`、Esc 或再次点击“参考”结束选择并保持当前视口，已选内容保留。退出选择后恢复输入框焦点，继续按 Esc 可关闭输入框。

## 系统如何运行

```text
App → 按地址显示 HomePage（列表 / 新建）或 CanvasPage
CanvasPage → Vue Flow 空画布 + 背景
                       ↑           ↓
                拖动 / 滚轮     viewport { x, y, zoom }
                                   ↓
                        CanvasToolbar 显示缩放比例
                                   ↓
                        点击按钮 → Vue Flow 视口方法
```

Vue Flow 内部视口是唯一视口状态源，工具栏只接收比例并发出操作事件。工具栏、标题和提示位于画布变换层之外，不随画布缩放或平移；背景、节点和连线跟随视口变化。节点由同一个 Vue Flow 实例维护，连线由节点的引用关系派生。

右键时 `CanvasPage` 记录鼠标的屏幕坐标并显示 `CanvasContextMenu`；菜单组件维护“第一层 / 添加节点”展示状态，并根据实际面板大小处理边缘定位。菜单位于画布变换层之外，点击和滚轮不会传入画布。

```text
右键 → 菜单 → 添加图片 / 视频 → 屏幕坐标换算为画布坐标 → 创建空节点
           ↓ 上传
       保存创建坐标 → 本地文件选择器 → 检查类型和非空
                                   ↓
                    为每个文件创建临时 blob 地址和节点
                                   ↓
                      MediaNode 用 img / video 读取文件
                                   ↓
                  loading → ready（尺寸和预览）/ error
```

`useMediaNodes` 管理创建、读取状态、尺寸更新和临时地址；`MediaNode` 负责实际媒体显示并报告加载结果。每条节点记录包含唯一 ID、画布位置、媒体类型、名称、读取状态，以及可选的临时地址和原始尺寸。手动添加的节点状态为 `empty`。

点击节点后，`CanvasPage` 记录正在编辑的节点 ID，并将节点边界从画布坐标换算到屏幕坐标；`NodePromptPanel` 据此显示在节点附近。面板位于画布变换层之外，输入和滚动文字不会拖动节点或缩放画布。放大只改变面板大小和位置，不创建另一份输入内容；输入内容通过 `updatePrompt` 写入对应节点的 `data.prompt`，切换节点不会串用草稿。视频控件的点击从打开面板的事件中排除，右键菜单和提示词面板不会同时展开。

导入文件先通过 `URL.createObjectURL` 生成即时预览。OSS 未启用时只保留本地预览；启用后，成功解码的文件按队列通过后端保存到 OSS，节点在保存期间显示“保存中…”，失败时显示原因和重试入口；成功后不显示角标。启用数据库时先保存节点，后端再上传文件并登记资源。当前页面仍复用本地预览以避免视频重载；刷新从数据库读取 Object Key，经后端重新读取 OSS 文件。组件卸载或媒体读取失败时释放临时地址；`blob:` 本身不入库，也不能用于刷新恢复。

技术选择：前端采用 Vue 3 + TypeScript + Vite + Vue Flow，将视口能力交给库，暂不引入前端 Router 或 Pinia。后端采用 Go + Gin，以标准 HTTP 客户端调用方舟，只有本地配置读取使用 godotenv，不需要额外模型 SDK。

## 图片生成如何运行

```text
图片节点输入提示词、选择模型和可选参考 → 点击生成 → 固定节点 ID、提示词、模型和参考资源快照
  ↓
POST /api/images/generations { taskId, prompt, model, canvasId, nodeId, referenceKeys? }
  ↓ Vite 开发代理转发到 127.0.0.1:8080
Gin：校验输入 → PostgreSQL 创建 queued 任务 → 返回 202 + 任务 ID
  ↓ 后台执行器读取任务并写 running，前端每 2 秒查询
  ↓
Ark Client：从后端配置读取密钥，按 Lite / Pro 能力组合请求参数，调用方舟
  ↓
先记录模型 URL / 模型 / 尺寸，状态 saving；启用 OSS 时转存结果
  ↓
事务写入资源与 succeeded 任务；未启用 OSS 或转存失败保留临时地址和提示
  ↓
原节点载入图片，读取实际像素尺寸并展示
```

生成接口接收提示词、模型 ID、画布和节点 ID，以及可选的有序 referenceKeys。后端读取参考图片头进行校验，并签发 10 分钟有效的 OSS 地址，仅作为 image 参数发送给模型；本地文件保存使用独立上传接口。前端同源请求由开发代理转发，模型与存储密钥只由后端使用，不进入前端源码或构建产物。后端只允许两个已配置模型；Pro 不支持 Lite 的组图模式和流式输出参数，因此由 Ark 适配层省略这些字段。详细契约见 [后端说明](../backend/README.md)。

前端把媒体读取状态与模型生成状态分开维护：已经显示的图片可以在再次生成时保留，生成失败不会清空旧图；请求与最初的节点 ID 绑定，避免用户切换面板后结果写错节点。被其他节点引用的图片更新时，短暂的加载状态不删除已有关系，读取失败时才清理失效引用。

启用数据库后，同节点未完成任务约束和 taskId 唯一性由数据库保证；图片默认并发 1、视频默认并发 3，其余持久化等待。后台执行器独立于浏览器请求，刷新不取消任务。图片参考准备与模型调用受超时控制，图片转存最多 90 秒；前端提交后轮询。图片生成期间后端中断会记录 interrupted，未自动重跑付费模型；已提交的视频恢复原供应商 ID 查询，saving 任务只继续转存。图片生成成功但转存失败保留临时结果并显示提示。完整状态机与中断边界见 [生成队列](./generation-queue.md) 和 [持久化说明](./persistence.md)。

## 参考功能的数据流与设计

```text
用户打开目标节点的提示词面板 → 点击“参考”
  ↓
useNodeReferences 记录 referenceTargetId → 进入选择模式
  ↓
CanvasPage 根据模式分流节点点击，不切换当前编辑目标
  ↓
校验来源存在、不是自身、已成功加载、类型匹配、未重复
  ↓
目标节点 data.referenceIds 追加来源节点 ID
  ├─ 根据 ID 读取素材名称 / 类型 / 地址 → 输入面板显示编号缩略图
  └─ 根据来源 ID 和目标 ID 派生 edges → Vue Flow 绘制曲线
  ↓
移除缩略图 → 删除该来源 ID → 缩略图和连线一起消失
```

例如目标视频节点 C 引用图片 A 和视频 B，C 的数据保存 `referenceIds: ['A', 'B']`。A、B 自己保存素材信息；C 不复制媒体文件或临时地址。显示的两条边分别为 `A → C`、`B → C`。同一个来源可被多个目标引用，每个目标维护自己的列表，移除其中一条不会影响其他目标。

每个目标维护有序来源 ID 列表；从整个画布看，节点间形成多对多引用。关系随画布快照保存到 PostgreSQL JSONB，没有单独中间表或 Redis。点击生成时解析为已保存的参考资源 Key，作为任务快照交给后端，详见图片生成说明。

重要设计与原因：

1. **一份关系数据，多种显示。** `referenceIds` 是业务关系的唯一来源；缩略图和连线都是计算结果。添加 / 删除只修改 ID 列表，避免分别维护边和缩略图导致漏删、不同步。
2. **明确交互状态。** `referenceTargetId` 为空时是普通编辑，有有效目标时是参考选择。来源点击必须加入该目标的引用，不能按原有“点击节点就打开对应面板”的逻辑切走。退出时清空选择模式，保留已提交的引用；这是立即添加，不存在未提交的确认批次。
3. **规则集中且重复操作安全。** 显示候选状态和真正写入都使用同一套可用性规则；写入入口再次校验并去重。灰色外观本身不能保证数据正确；重复点击不会重复连线。素材后来读取失败时，监听可用性变化，清理引用它的所有目标。
4. **图形层与业务层分工。** 自己实现引用规则、关系和状态；Vue Flow 提供节点拖动、坐标变换、端点定位及曲线绘制。输入面板与顶部提示在屏幕层，节点与边在画布变换层。未开放手动拖线，避免绕过引用入口。
5. **事件与资源边界。** 视频播放、输入、节点选择分别处理。参考缩略图复用源节点临时地址，移除引用不会释放仍被源节点使用的地址；源媒体失效时才由媒体管理模块释放资源并触发引用清理。

面试中可以讲：使用 Vue 3 / TypeScript / Vue Flow 实现媒体画布，重点负责引用关系建模、选择模式的事件分流、类型约束、去重、派生视图一致性，以及浏览器交互验证。能够具体解释为什么点击同一个节点在不同模式下产生不同动作、为何不同时维护两份关系数据，比只说“调用库画线”更有内容。

实现边界：连线代表对已有素材的引用，尚不是自动执行的工作流；没有依赖调度或环检测。引用随画布持久保存，图生图任务保存有序 OSS 资源 Key 快照，由后端签发临时地址交给模型。现已实现邮箱密码登录和用户资源隔离；没有团队协作或商业生产环境验证。
