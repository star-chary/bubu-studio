# 提示词库

状态：提示词库已于 2026-11-08 上线，2026-11-09 发布前台移动端滚动修复。本次前端发布没有调用付费图片或视频生成接口。

## 使用方式

- 首页侧边栏「首页」回到现有画布列表；「提示词」显示公开提示词。访客无需登录即可访问列表、图片和大图，也可搜索或复制完整文字；前台不提供新增或管理入口。
- 管理员在后台「提示词管理」新增、编辑和删除内容，支持一次选择多张图片、移除未上传图片及删除已上传图片。单张图片上限为 20 MiB，支持 JPEG、PNG、WebP、GIF、AVIF、BMP，以服务端实际文件内容校验为准。
- 保存时先保存文字，再依次上传图片。新内容保存文字后便会公开；如果部分图片上传失败，管理页保留未完成的图片，提示再次保存重试。每张待上传图片重试使用同一编号，避免确认成功后重复添加。
- 界面按上传顺序展示图片。卡片支持左右滑动和键盘方向键，并可点击查看完整大图。

## 数据与权限

`009_prompt_library.sql` 新增三张表：`prompt_library` 保存标题和正文；`prompt_library_images` 通过 `prompt_id` 一对多关联图片及其对象存储键；`prompt_image_cleanup` 保存待清理的对象键。删除提示词时，关联图片记录通过外键级联删除，对象键在同一数据库事务中进入清理表。

图片保存在现有 OSS 的 `prompt-library` 独立目录。`GET /api/prompts` 和 `GET /api/prompt-images/:id` 是公开只读接口，后者先在提示词图片表查找键再读取对象；它不能通过任意对象键访问图片。原有 `/api/assets/content` 仍需登录且校验画布归属。列表支持关键词、分页，图片内容不在列表中重复传输。

`/api/admin/prompts` 及其下级写入接口继续使用现有登录会话、管理员角色、请求来源和 CSRF 校验。前台没有管理按钮不是权限依据：普通账号和访客的管理写入也会被后端拒绝。

数据库提交与 OSS 删除无法成为同一个事务，因此删除后先从公开数据中移除图片，再尝试清理 OSS。清理失败的键保留在数据库中，在管理员后续打开提示词列表或执行删除时继续尝试，单次处理有短时间限制；这不是定时清理任务。上传后若数据库写入和对象清理同时失败且无法写入清理表，服务端日志会记录对象键，需人工排查。

## 上线注意

后端启动时会自动执行新迁移；上线前应按项目现有流程备份数据库，并同步发布前端、后端和管理端。`deploy/nginx/studio.example.conf` 包含单张 20 MiB 的管理图片上传规则；正式环境必须将该 `location` 合并进当前正在使用的 Nginx 配置，执行 `nginx -t` 并按发布流程重载，不能用示例文件直接覆盖现有站点配置。未合并时，原有 2 MiB 限制可能拒绝较大图片。

## 验证边界

Go 集成测试使用独立 PostgreSQL 测试库和模拟对象存储，覆盖访客读取、普通用户及无 CSRF 写入拒绝、管理员上传和删除、图片删除失败后重试清理，以及私有画布资源的访问限制。浏览器测试使用模拟 API，覆盖前台访问、搜索、滑动、大图和复制，以及后台新增、多图上传失败重试、编辑和删除。没有验证正式环境 OSS 的真实上传、删除或正式 Nginx 配置。
