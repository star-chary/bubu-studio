## 使用方式

- `/` 对访客显示公开首页，只有登录和创建画布入口；不调用个人画布与积分接口。登录后才显示“我的画布”，按最近修改时间排列，24 张一页，可加载更多。卡片显示名称、短 ID、节点数、修改时间和保存过的节点布局，最多预览 36 个节点；预览不是媒体缩略图。
- 访客点击创建进入登录／自动注册表单；认证成功后自动打开命名弹窗，确认名称时才调用画布创建接口。直接访问 `/?canvas=<UUID>` 也先登录，登录后仍检查画布归属。
- 名称可选，最多 80 字，空名称默认“未命名画布”。创建成功后进入 `/?canvas=<UUID>`。旧画布补上默认名称，原有链接继续可用。
- 点击卡片只读取该画布，不会新建。重新打开恢复节点、草稿、模型、引用、视口、资源和任务。
- 左上角“首页”先等待保存，失败或冲突留在原页面。本地素材尚未上传时，允许继续等待 / 重试，或明确确认离开。仅保存画布不能保存本地文件。
- 浏览器后退、刷新、关闭沿用未保存提示；历史缓存恢复时重新读取页面。已提交的数据库生成任务在后端继续运行，重新打开原画布后继续查询。
- 持久画布加载失败不会被替换为空白临时画布。数据库未配置时，访客仍能查看公开首页及登录服务不可用提示；画布深链显示重试，不提供匿名临时入口。

## 请求与数据流

```text
访客首页 → GET /api/auth/me 返回 401 → 仅渲染公开入口，无个人数据请求
访客点击创建 → POST /api/auth/login → 认证成功 → 打开命名弹窗
登录后首页 → GET /api/canvases → Gin → Store → PostgreSQL canvases
确认新建 → 分配 UUID → POST /api/canvases { id, title }
     → 插入空画布 → 成功后导航到 /?canvas=<UUID>
打开 → GET /api/canvases/:id → 恢复该 ID 的快照、资源与任务
编辑 → 原有串行自动保存 → PUT /api/canvases/:id
首页按钮 → 等待保存完成 → 导航到 / → 重新查询列表
```

画布是独立文档，UUID 是归属标识。`canvases` 保存快照，`assets.canvas_id` 和 `generation_tasks.canvas_id` 指向其所属画布。本次没有新增表、缓存、消息队列或第三方服务。

迁移 `003_canvas_library.sql` 只为 `canvases` 增加 `title`、名称长度约束和最近修改排序索引，保留旧快照、版本、更新时间、素材与任务。主库迁移前已备份到 `.data/backups/before-canvas-library-2026-10-04.dump`。

`GuestHomePage.vue` 只展示公开入口；`HomePage.vue` 管理登录后的列表与新建表单，`App.vue` 按地址和登录状态选择页面。完整页面导航建立新的 Vue Flow 实例、上传队列、提示词和任务查询会话，无需新增 Router 或 Pinia。`useCanvasSession` 仅按传入 ID 恢复，不再读取或写入 `frame-space:canvas`，也不隐式创建画布。

一次新建表单始终使用同一个 UUID，丢失响应后重试不会重复创建或覆盖原记录，依靠数据库主键和 `ON CONFLICT DO NOTHING` 保证。原有保存版本比较与串行请求继续防止旧页面覆盖更新内容。

## 接口

| 接口 | 契约 |
| --- | --- |
| `GET /api/canvases?limit=24&offset=0` | `{ canvases, hasMore }`；limit 为 1～100、offset 为 0～100000；按 `updated_at DESC, id DESC` 排序。摘要含 `id/title/updatedAt/nodeCount/preview`，预览仅有节点位置与类型，不传提示词、文件地址或任务输入。 |
| `POST /api/canvases` | `{ id, title? }`；去除名称首尾空白后默认“未命名画布”，超过 80 个 Unicode 字符返回 400；返回 201 与完整画布。同 ID 重试返回原记录。 |
| `GET /api/canvases/:id` | 原恢复响应新增 `title`；不存在返回 404，不自动创建。 |
| `PUT /api/canvases/:id` | `{ version, snapshot }` 不变；保存内容更新排序时间，不修改名称。 |

## 边界

当前为独立账号的私有画布，无分享或多人协作。列表、详情、保存、素材和任务已统一检查用户归属，服务仍只监听本机。不同用户和画布可以同时提交任务，默认视频并发 3、图片并发 1，其余持久化等待；同节点只允许一个未完成任务，见 [生成队列](./generation-queue.md)。
