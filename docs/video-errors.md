# 视频生成错误分类

2026-10-16。视频创建和异步生成失败按方舟错误码转换为中文提示；未知错误明确标为尚未识别，不猜测为素材、权限或余额问题。

## 数据与状态流

```text
方舟 HTTP 状态 + error.code / error.message / error.param
→ 后端识别错误类别，从实际请求布局换算参考素材编号
→ 只生成固定中文说明和经过校验的序号
→ generation_tasks.error 保存 code / message
→ 原有任务轮询 → 节点提示及任务记录
```

供应商原始 message 仅在内存中用于识别素材位置或有限的错误特征，不直接返回前端、写数据库或输出到日志。后台记录 HTTP 状态、本地任务 ID 或供应商任务 ID、供应商错误码及请求 ID；诊断标识只接受有限长度的安全字符，并过滤当前 API Key。原始提示词、签名地址和素材内容不进入错误日志。

沿用现有 `error: { code, message }`、任务表和前端展示，不新增表、迁移、中间件或第三方服务。`VideoRequest.TaskID` 只用于关联本地诊断日志，不发送给方舟。

## 可区分的错误

创建请求明确被拒绝时，具体原因使用 `VIDEO_REJECTED_<原因>`；已受理任务失败使用 `PROVIDER_<原因>`。以下为主要分类，后缀及完整映射以 `backend/internal/ark/video_errors.go` 为准。

| 场景 | 提示重点 |
| --- | --- |
| 图片 / 视频被判可能含真人 | 人像审核，提交阶段尽可能列出对应参考序号 |
| 图片 / 视频 / 音频未通过内容审核 | 指明参考类型和可确认的序号 |
| 提示词审核 | 明确需要检查提示词 |
| 输入或输出涉及版权限制 | 说明供应商版权判定，不与普通审核混为一类 |
| 输出视频 / 音轨等未通过审核 | 说明生成结果未能返回 |
| 参数无效 / 缺少参数 / 任务类型冲突 | 区分三种情况；已识别参数名时显示时长、分辨率等中文名称 |
| 参考图片解析失败 / 参考素材下载失败 | 检查文件格式、完整性或访问地址 |
| 凭据无效 / 无权限 / 模型未开通 / 模型不可用 | 区分管理员需要检查的配置 |
| 供应商账号欠费 / 账号异常 / 用量上限 | 不将这些错误统一写成 API Key 问题 |
| 调用频率 / 并发 / 配额 / 服务繁忙 | 分别说明限制；`QuotaExceeded` 可能指排队上限，不直接认定为欠费 |
| 异步任务过期 / 被取消 | 明确终止原因 |
| 未知错误 | 提示联系管理员查看任务诊断记录 |

供应商未返回可识别错误体时，HTTP 401、403、404、413、429 有各自的保守提示；其他明确 4xx 保留 `VIDEO_REJECTED`。兼容既有 `MODEL_AUTH_FAILED`、`MODEL_LIMITED` 等历史代码。

## 参考序号

方舟的 `content[n]` 是零起始数组位置。存在提示词时，`content[0]` 是文本；空提示词不会插入文本项。平台按图片、视频、音频分别编号，因此不能简单把 n 当成素材序号。

例如请求为「文本、图片、视频、图片」，`content[3]` 对应图片 2。解析会校验下标、素材类型、去重，并按原参考顺序显示；错误中缺少有效下标时只显示素材类型。异步任务查询不持有原始提交布局，因此当前异步提示只说明类型，不推测图片编号。

## 积分和重试

- 明确的创建拒绝，包括新增 `VIDEO_REJECTED_*`，仍在任务结束事务中退回冻结积分。
- 供应商已明确返回失败、过期或取消的任务，沿用已有退回规则。
- 网络异常、HTTP 408 / 499 / 5xx、重定向或缺少有效任务 ID 的成功响应，仍为 `interrupted / SUBMISSION_UNKNOWN`，冻结积分保留待核查。
- 所有创建请求只发送一次，不因更细的错误分类自动重新生成。
- 进度查询失败仍查询原供应商任务 ID，不创建替代任务。
- 历史失败未保留供应商原始响应，不能可靠补齐具体原因；本次不回写旧任务。
