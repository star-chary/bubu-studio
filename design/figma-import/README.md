# 帧间 · Figma 原型导入包

这是视频平台第一版的**交互设计演示**，不是前后端项目。
“帧间”仅为原型临时名称，可以在设计阶段更改。

## 当前交付状态

- 已在你的 Figma 账号中创建文件：<https://www.figma.com/design/CFT4ktk72dnymi1O2yLNDU>。
- 在线文件已绘制默认画布、图片生成节点、浮动编辑区和空画布引导，并检查了主界面截图。
- Figma MCP 在继续制作时返回 Starter 套餐调用额度限制。其余在线状态仍是未完成的副本，**在线稿尚未完成交互连接**。
- 此导入包包含完整的本地生成脚本。运行后新增一个页面，包含 26 个界面／说明状态以及点击连接，不覆盖已有页面。
- 本地脚本检查与模拟 API 测试不能替代 Figma 运行验证；目前尚未在真实 Figma 桌面端运行此导入包。

## 在 Figma 中导入

1. 使用 **Figma 桌面端**打开上述设计文件。
2. 在菜单中选择 **Plugins → Development → Import plugin from manifest…**，选择本目录的 `manifest.json`。
3. 在 **Plugins → Development** 中运行 **帧间 · V1 交互原型导入**。
4. 完成后进入 **V1 · 完整交互原型** 页面，选中 **开始这里 · V1 说明与导航**，点击右上角的演示按钮。

官方导入说明：<https://help.figma.com/hc/en-us/articles/360042786733-Create-a-plugin-for-development>

无需 API Key，无需 npm 安装，插件无网络访问。中文字体优先使用 Noto Sans SC，若不可用会尝试可用的微软雅黑或苹方 Regular 字体。字体不可用时会在新建页面前停止。

## 建议体验顺序

从上传开始 → 选择示例图片 → ＋图片 → ＋参考 → 点击陈志远图片 → 点击提示词区域 → 选择文件名 → 放大／恢复 → 生成 → 用作视频参考 → 生成视频。

输入、搜索、上传、生成、播放和下载使用预设状态。真正的无限画布平移、缩放、节点拖动和任意文字输入尚未实现。
图片和视频结果使用用户提供截图中的示例画面，不是模型实际输出；模型参数列表和价格仍待验证。

## 可编辑内容

- 节点、文案、编辑区、参数栏、参考列表均为独立图层。
- 按钮采用组件实例，可通过 Label 属性修改文案。
- 颜色为 `帧间 V1 / Dark` 变量，素材为图片填充。
- 在 Prototype 面板中可查看、修改各界面之间的跳转。
- 原型页面之外保留原有在线稿件，不做删除和替换。

## 重复运行与恢复

- 若已有 `V1 · 完整交互原型` 页面，脚本只切换到该页面，不重复生成或覆盖修改。
- 若导入中断，原有页面仍保留；查看错误后，可删除本次新增的 `V1 · 完整交互原型 · 构建中` 页面再重试。
- 构建失败可能留下本次新建的 `帧间 V1 / Dark` 变量集合；仅在确认没有图层引用它时手动清理。

## 文件用途

- `manifest.json`：Figma 导入入口。
- `code.js`：可直接运行的生成脚本，已内嵌示例截图。
- `source.js`：便于修改的脚本源文件。
- `build.cjs`：修改源文件后，重新嵌入原始截图生成 `code.js`。
- `validate.cjs`：检查页面连通性、跳转目标和脚本生成结构；不代表真实 Figma 渲染测试。

## 设计验收

1. 默认编辑区及放大编辑区显示相同的提示词与参考文件名。
2. 缩略图序号与 `@` 文件名含义区分明确。
3. 选择参考时仍能识别正在编辑的生成节点。
4. 生成中、成功、失败状态可以区分；失败后保留输入。
5. 图片结果能作为视频节点参考继续创作。
6. 生成、上传等模拟能力没有被误认为真实服务。
